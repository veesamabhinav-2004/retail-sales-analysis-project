# Retail Sales Analysis Project

## Objective
Analyze retail sales data to identify trends, top-performing products, and regional performance.

## Tools Used
- Python (Pandas, Matplotlib, Seaborn)
- SQL
- Tableau

## Project Components
- Data Cleaning and Analysis using Python
- SQL Queries for Business Insights
- Tableau Dashboard Visualization
- Project Report (PDF)

## Key Insights
- Technology category generated highest sales
- West region showed best performance
- Top products contribute major revenue
- Sales show growth over time
